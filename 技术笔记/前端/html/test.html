1.滚动器

div布局

container wrapper item

container——固定容器,宽度固定,禁用滚动条及滚动事件,超出隐藏

wrapper——包裹内部容,宽度=i1+i2+...+in其宽度之和

滚动方式

滚动采用获取Touches对象,获取触摸坐标，使用translate对当前位置进行平移，从而模拟出滚动效果

2.惯性模拟

惯性的发生时机是在触摸滑动结束后的滑动延续

特点: 在触摸滑动结束瞬间的瞬时滑动速度上，做减速运动直到静止，由最后滑动结束所受的摩擦可以自定义，及加速度可以自定义，从而可以模拟出在不同粗糙平面滑动的效果

cur——当前坐标

Δv——手指离开的速度: （最后两次触摸移动事件的触发的瞬时速度）Δx/Δt

Δt——时间临界值: 单次事件循环所消耗的单位时间

Δx——时间临界值: (最后连词触摸移动事件的瞬时位移）

a——力度套用公式计算得到加速度 a = ((v >> 31) * 2 + 1) * 0.5 （经验粗糙平面，速度大到一定程度时才会有所不同)可以调节)

计时器，迭代至v < 1: v = v - a; cur = cur + v (以当前速度一个单位时间的位移); 此时的单位时间右自己定义为20ms

3.弹力模拟--两种情况

触发时机——触摸滑动到容器边界以外

flex——弹力系数,自定义150

cur > 0时,右滑极限 cur = cur * flex / (cur + flex) 可见当拉动越远 cur -> flex 趋于一个flex定值，无法再拉动超出flex的距离

cur < 0时,左滑极限 cur = cur * flex / (cur - flex) - （wrapper宽 - 容器宽) 可见当拉动越远 cur -> flex 趋于一个flex定值，无法再拉动超出flex的距离

4.回弹擦除

offset——惯性滑动越界最大偏移量

触发时机：

* 触摸滑动结束

* 惯性滑动超出滑动出容器最大偏移

* 惯性滑动未超出容器最大偏移，但速度已降至接近于0

左极限临界坐标——wrapper宽-容器宽

右极限临界坐标——0

对应以上三种情况，分别对应超出左右临界的情况进行反向滑动，从而实现反向擦除的效果

计时器, 迭代至｜cur-临界值｜< 1: cur = cur - (cur - 临界值) * 0.2, 按照该公式进行单位时间20ms, 0.2的比例进行距离衰减, 从而滑动到极限临界坐标

5.联动滑动

在同一事件循环，同一次UI渲染中完成dom计算

此处只是监听触摸事件但禁用了默认的滚动行为，在事件中对多个滚动器进行相同的样式赋值，促使其在同一循环进行渲染，从而得到同步效果
