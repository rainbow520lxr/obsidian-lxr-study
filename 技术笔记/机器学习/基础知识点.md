## 基础数据工具
---
主要是numpy和pandas，用于Python中的数据分析和科学计算。
### Numpy
Numpy是Python中用于高性能科学计算的核心库，提供多维数组对象和数学函数。
#### 特点

- **高性能**：基于C语言实现，支持向量化操作，计算效率高。
- **多维数组**：支持一维、二维及以上数组（如向量、矩阵）。
- **广播机制**：允许不同形状数组进行算术运算。
- **丰富函数库**：包括数学、逻辑、线性代数等函数。
#### 基本概念

- **维数（ndim）**：数组的维度数，例如一维数组的ndim为1。
- **形状（shape）**：表示每个维度的大小，返回元组（如(3,2)）。
- **元素数量（size）**：数组中总元素个数。
- **元素类型（dtype）**：数据类型，如int32、float64，影响存储和计算。
#### 数组操作

- **一维数组**：使用`np.array([1, 2, 3])`创建。
- **字符串操作**（通过`np.char`模块）：
    - 大小写转换：`np.char.lower(array)`、`np.char.upper(array)`
    - 字符串分割：`np.char.split(array, sep=' ')`，按分隔符分割。
    - 字符串替换：`np.char.replace(array, old, new)`，替换子字符串。

示例代码：
```python
import numpy as np
arr = np.array(['Hello', 'WORLD'])
print(np.char.lower(arr))  # 输出：['hello' 'world']
```
### Pandas

Pandas是Python中用于数据操作和分析的库，核心数据结构是DataFrame和Series。
#### 特点

- **数据框（DataFrame）**：二维表格型数据结构，带标签轴。
- **灵活索引**：支持行和列标签访问数据。
- **处理缺失值**：自动识别和处理NaN值。
- **时间序列支持**：内置日期和时间功能。
#### 基本操作

- **head()和tail()**：查看数据的前n行或后n行，默认n=5。
    - 示例：`df.head(3)` 显示前3行。
- **读取文本数据**：使用`pd.read_csv()`、`pd.read_table()`等函数。
- **写入文本数据**：使用`df.to_csv()`、`df.to_excel()`等导出数据。
- **创建方式**：从字典、列表或NumPy数组创建，例如`pd.DataFrame({'col': [1,2]})`。
#### 属性和元数据

- **形状**：`df.shape`，返回行数和列数。
- **列名**：`df.columns`，可修改或访问。
- **数据类型**：`df.dtypes`，显示每列的数据类型。
- **索引**：`df.index`，行标签信息。
#### 数据操作

- **二元运算**：元素级算术运算，如`df + 1`或`df1 + df2`。
- **非缺失值计数**：`df.count()`，返回每列非NaN值的数量。
- **数据摘要描述**：`df.describe()`，提供数值列的统计摘要（如均值、标准差）。
#### 文本数据处理

- **解析选项**：在读取数据时使用参数，如`dtype`指定类型、`parse_dates`解析日期。
- **文本数据类型**：列类型为object或string，使用字符串方法处理。
- **大小写转换**：`df['col'].str.lower()`、`df['col'].str.upper()`
- **长度**：`df['col'].str.len()`，计算字符串长度。
- **处理空格**：`df['col'].str.strip()`，去除字符串前后空格。

示例代码：

```python
import pandas as pd
df = pd.DataFrame({'text': ['  Hello  ', 'WORLD']})
df['text_clean'] = df['text'].str.strip().str.lower()
print(df)
```

## 统计学
---

统计学是通过收集、整理、分析和解释数据来获取信息和做出决策的科学。
### 基本概念

#### 统计学定义与分类
- **描述性统计**：对数据进行总结和描述，不进行推断
  - 包括：均值、中位数、标准差等
  - 目的：了解数据的基本特征和分布
- **推断性统计**：基于样本数据对总体进行推断
  - 包括：假设检验、置信区间、回归分析
  - 目的：从样本推广到总体

#### 核心术语详解
| 术语  | 详细描述               | 应用场景                     |
| --- | ------------------ | ------------------------ |
| 总体  | 研究对象的全部个体集合，用$N$表示 | 研究全国人口时，所有公民就是总体         |
| 样本  | 从总体中抽取的部分个体，用$n$表示 | 随机抽取1000人进行问卷调查          |
| 参数  | 描述总体特征的固定数值        | 总体均值$\mu$、总体方差$\sigma^2$ |
| 统计量 | 基于样本计算得出的数值        | 样本均值$\bar{x}$、样本方差$s^2$  |

### 概率论基础

#### 基本概念详解
- **概率定义**：事件发生的可能性度量
  - 取值范围：$0 \leq P(A) \leq 1$
  - $P(A)=0$：不可能事件
  - $P(A)=1$：必然事件
- **条件概率**：在事件B发生的条件下，事件A发生的概率
  - 公式：$P(A|B) = \frac{P(A \cap B)}{P(B)}$
  - 例子：已知某人患病，检测呈阳性的概率
- **贝叶斯定理**：根据新证据更新概率
  - 公式：$P(A|B) = \frac{P(B|A)P(A)}{P(B)}$
  - 应用：垃圾邮件过滤、医学诊断

#### 重要概率分布
| 分布类型 | 特点 | 应用场景 |
|----------|------|----------|
| 正态分布 | 钟形曲线，对称分布 | 身高、体重等自然现象 |
| 二项分布 | 固定试验次数的成功概率 | 抛硬币、质量检测 |
| 泊松分布 | 单位时间内事件发生次数 | 客服电话数量、交通事故 |

### 重要定理详解

#### 大数定律
- **核心思想**：随着样本量增加，样本均值趋近于总体均值
- **数学表达**：$\bar{X}_n \xrightarrow{P} \mu$ 当 $n \to \infty$
- **实际意义**：
  - 长期来看，随机事件的频率稳定于概率
  - 保险精算、赌博游戏的理论基础
- **示例**：抛硬币次数越多，正面朝上的比例越接近50%

#### 中心极限定理
- **核心思想**：无论总体分布形态，样本均值的分布近似正态
- **数学表达**：$\frac{\bar{X} - \mu}{\sigma/\sqrt{n}} \xrightarrow{d} N(0,1)$
- **实际意义**：
  - 为参数估计和假设检验提供理论基础
  - 样本量$n \geq 30$时效果较好
- **应用**：质量控制、民意调查

### 数据收集方法详解

#### 抽样技术比较
| 方法 | 操作步骤 | 优点 | 缺点 |
|------|----------|------|------|
| 简单随机抽样 | 每个个体等概率被选 | 无偏性好 | 需要完整抽样框 |
| 分层抽样 | 按特征分层后抽样 | 保证各层代表性 | 需要先验知识 |
| 系统抽样 | 按固定间隔选择 | 操作简单 | 可能有周期性偏差 |
| 整群抽样 | 以群组为单位抽样 | 成本低、效率高 | 精度相对较低 |

#### 数据质量要素
- **准确性**：数据与真实值的接近程度
  - 影响：错误的决策依据
  - 控制：数据验证、交叉检查
- **完整性**：数据缺失的程度
  - 影响：分析结果的可靠性
  - 处理：删除、插补缺失值
- **时效性**：数据的时间相关性
  - 影响：分析的现实意义
  - 要求：根据分析目的确定时间窗口

#### 常用统计图表详解

**直方图**
- **用途**：展示连续数据的分布
- **解读要点**：
  - 形状：对称、偏态、双峰
  - 中心：数据集中位置
  - 离散：数据分散程度
```python
import matplotlib.pyplot as plt
import numpy as np

data = np.random.normal(0, 1, 1000)
plt.hist(data, bins=30, alpha=0.7, color='blue')
plt.title('数据分布直方图')
plt.xlabel('数值')
plt.ylabel('频数')
plt.show()
```

**箱线图**
- **用途**：识别异常值、比较分布
- **组成部分**：
  - 箱体：25%-75%数据范围
  - 中位数线：数据中心位置
  - 须线：正常值范围
  - 异常点：超出1.5倍IQR的值
```python
data = [np.random.normal(0, 1, 100), 
        np.random.normal(2, 1, 100)]
plt.boxplot(data, labels=['组A', '组B'])
plt.title('组间比较箱线图')
plt.show()
```

**散点图**
- **用途**：分析两个变量关系
- **解读要点**：
  - 方向：正相关、负相关
  - 强度：相关程度
  - 形态：线性、非线性
```python
x = np.random.normal(0, 1, 100)
y = 2*x + np.random.normal(0, 0.5, 100)
plt.scatter(x, y, alpha=0.6)
plt.title('变量关系散点图')
plt.xlabel('X变量')
plt.ylabel('Y变量')
plt.show()
```

### 描述性统计量详解

#### 集中趋势度量
- **均值**：$\bar{x} = \frac{\sum_{i=1}^{n} x_i}{n}$
  - 优点：使用所有数据
  - 缺点：受异常值影响大
- **中位数**：排序后的中间值
  - 优点：不受异常值影响
  - 缺点：忽略数值大小信息
- **众数**：出现频率最高的值
  - 优点：适用于分类数据
  - 缺点：可能不唯一

#### 离散程度度量
- **方差**：$s^2 = \frac{\sum (x_i - \bar{x})^2}{n-1}$
  - 衡量数据与均值的平均偏离
- **标准差**：$s = \sqrt{s^2}$
  - 与原始数据同量纲，更易解释
- **四分位距**：$IQR = Q_3 - Q_1$
  - 中间50%数据的范围，稳健的离散度量

### 统计分析流程详解

1. **问题定义阶段**
   - 明确研究目标
   - 确定分析变量
   - 建立研究假设

2. **数据收集阶段**
   - 选择抽样方法
   - 设计数据收集工具
   - 实施数据收集

3. **数据清洗阶段**
   - 处理缺失值：删除或插补
   - 识别异常值：箱线图、3σ原则
   - 数据转换：标准化、归一化

4. **探索分析阶段**
   - 描述性统计汇总
   - 数据可视化探索
   - 变量关系初探

5. **统计推断阶段**
   - 参数估计：点估计、区间估计
   - 假设检验：t检验、卡方检验
   - 模型建立：回归分析、方差分析

6. **结果解释阶段**
   - 统计显著性判断
   - 实际意义分析
   - 结论和建议提出
