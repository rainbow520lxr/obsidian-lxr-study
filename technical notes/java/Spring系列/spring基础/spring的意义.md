# 为什么spring

 ## spring应用场景无处不在

1. 为开发者提供了灵活的扩展库
2. 拥有百万级终端用户流量的实战案例（提供了创新的解决方案)
3. 有大厂背书且众多知名企业也参与到sping项目的贡献

## 特性一：弹性的sping

以IOC和DI为基础同时提供了一系列扩展和三方库

## 特性二： 使用spring更容易让你的想法产品化

springboot通过自动配置和嵌入式webserver等简化了开发流程，可以更快的结合springboot和spring cloud系列的支持库、服务器、模式、模板等安全的将整个微服务架构部署到云上

## 特性三： spirng是够快

spring快速启停和优化执行、以及可以快速搭建项目

## 特性四： 够安全

Spring在快速、负责任地处理安全问题方面有着良好的记录。Spring提交人员与安全专业人员合作，修补和测试任何报告的漏洞。第三方依赖关系也受到密切监控，并定期发布更新，以帮助尽可能确保数据和应用程序的安全。此外，Spring Security使您更容易与行业标准的安全方案集成，并提供默认安全的值得信赖的解决方案。

## 特性五： 广泛支持

Spring社区规模庞大、全球化、多样化，涵盖了从完全初学者到经验丰富的专业人士的各个年龄段和能力。无论你在旅途中的哪个地方，你都可以找到所需的支持和资源，让你达到下一个水平：快速入门、视频、聚会、支持，甚至正式培训和认证。
