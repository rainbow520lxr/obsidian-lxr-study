## 1、 图像基础概念

### 1.1 图像组成

#### 基本构成要素

- **像素**：图像的基本单位，包含亮度、颜色信息
- **分辨率**：图像的尺寸，通常表示为宽度×高度（如1920×1080）
- **色彩深度**：每个像素的颜色信息位数（如8位、24位）
- **颜色空间**：RGB、HSV、YUV等不同的颜色表示方式

#### 图像表示

```python
# 数字图像通常表示为三维矩阵
# 对于彩色图像：高度 × 宽度 × 通道数
# 对于灰度图像：高度 × 宽度
```

### 1.2 轮廓识别

#### 基本概念

- **轮廓**：图像中物体的边界线，连接具有相同颜色或强度的连续点
- **边缘检测**：识别图像中亮度明显变化的区域

#### 轮廓识别方法

|方法|原理|特点|
|---|---|---|
|基于梯度|计算像素强度变化率|对噪声敏感|
|基于零交叉|寻找二阶导数的零点|对细边缘效果好|
|基于模板匹配|使用预定义模板进行匹配|计算简单|

### 1.3 特征识别

#### 特征类型

- **全局特征**：描述整个图像的特征（如颜色直方图）
- **局部特征**：描述图像局部区域的特征（如角点、边缘）
- **结构特征**：描述图像中物体的形状和空间关系

#### 特征属性

- **不变性**：对旋转、缩放、光照变化的鲁棒性
- **区分性**：能够区分不同物体的能力
- **稳定性**：在不同图像中保持一致性的能力

### 1.4 图像分类介绍

#### 分类流程

1. **特征提取**：从图像中提取有意义的特征
2. **特征选择**：选择最具区分性的特征
3. **分类器训练**：使用标注数据训练分类模型
4. **预测分类**：对新图像进行分类预测

#### 分类方法

- **传统方法**：基于手工特征+SVM/决策树等
- **深度学习方法**：基于卷积神经网络的端到端学习

### 1.5 色彩识别

#### 色彩空间

- **RGB**：红绿蓝三原色，面向硬件
- **HSV**：色调、饱和度、明度，面向人类感知
- **Lab**：亮度+颜色对立维度，感知均匀

#### 色彩特征提取

- **颜色直方图**：统计各颜色分量的分布
- **颜色矩**：描述颜色分布的统计特征
- **主色调**：图像中出现频率最高的颜色

### 1.6 物体识别

#### 识别层次

- **物体检测**：定位图像中物体的位置
- **物体识别**：识别物体的类别
- **实例分割**：对每个物体实例进行像素级分割

#### 识别挑战

- **视角变化**：不同角度拍摄的同一物体
- **光照变化**：不同光照条件下的识别
- **遮挡问题**：物体被部分遮挡的情况

### 1.7 信息获取与图像采集

#### 图像采集设备

- **数码相机**：基于CCD或CMOS传感器
- **扫描仪**：逐行扫描获取图像
- **医学影像设备**：CT、MRI、X光等

#### 图像数字化过程

1. **采样**：空间离散化，确定图像分辨率
2. **量化**：幅度离散化，确定颜色深度
3. **编码**：将数字信号转换为存储格式

### 1.8 应用场景

#### 计算机视觉领域

- **安防监控**：人脸识别、行为分析、异常检测
- **医疗影像**：病灶检测、细胞分类、手术导航
- **自动驾驶**：道路识别、障碍物检测、交通标志识别

#### 工业应用

- **质量检测**：产品缺陷检测、尺寸测量
- **机器人视觉**：物体抓取、环境感知
- **遥感图像**：土地利用分类、灾害监测

#### 消费电子

- **手机摄影**：人脸美化、场景识别
- **增强现实**：物体跟踪、虚实融合
- **图像搜索**：以图搜图、内容检索

- 能够突出感兴趣区域的细节
- 适用于灰度分布不均匀的图像

#### 伽马校正应用

```python
import numpy as np

def gamma_correction(image, gamma=2.2):
    """伽马校正函数"""
    # 归一化到[0,1]
    image_normalized = image / 255.0
    # 伽马变换
    corrected = np.power(image_normalized, 1/gamma)
    # 恢复为[0,255]
    return (corrected * 255).astype(np.uint8)
```

### Canny算子

#### 边缘检测流程

1. **高斯平滑**：去除噪声
2. **梯度计算**：使用Sobel算子计算梯度幅值和方向
3. **非极大值抑制**：细化边缘，保留局部最大值
4. **双阈值检测**：高低阈值确定强边缘和弱边缘
5. **边缘连接**：连接强边缘，保留与强边缘相连的弱边缘

#### 参数设置

- **高斯核大小**：通常5×5
- **高低阈值比**：通常1:2或1:3
- **梯度方向**：0°, 45°, 90°, 135°四个方向
